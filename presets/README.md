# Presets

Apply any of these with `../dx5.py apply <file>`. Add `--dry-run` first to see
the frames without sending them.

| File | What it is |
|---|---|
| `e3-oratory-harman-8k.txt` | **Dan Clark E3 correction, currently loaded.** oratory1990 measurement → Harman 2018 (KB501X) target, generated by Topping's Auto EQ with the correction capped at 8 kHz. 10 filters, preamp −1.5 dB, everything within ±2.1 dB |
| `e3-kuulokenurkka-autoeq.txt` | **Alternative E3 correction** from the AutoEQ project (Kuulokenurkka measurement). 10 filters, preamp −1.7 dB. Includes a high shelf at 10 kHz — see the caveat below |
| `bass1.json` | The Bass 1 shelves that were on the device before any of this: LS 200 Hz +6.0 and HS 3413 Hz +5.3, both Q 0.707 |
| `bass1-plus-1k-probe.json` | Bass 1 plus a deliberately obvious −12 dB notch at 1 kHz, Q 2.0. A listening test, not a correction — useful for confirming that PEQ writes are reaching the DSP |

## A/B-ing the two E3 corrections

```bash
../dx5.py apply presets/e3-oratory-harman-8k.txt
../dx5.py apply presets/e3-kuulokenurkka-autoeq.txt
../dx5.py flat                                     # no EQ, for reference
```

They come from **different measurements of the same headphone**, so any audible
difference is measurement variance and target choice, not one being "right".

## Two things worth knowing

**These corrections are subtle.** Every filter in the oratory/Harman preset is
≤ 2.1 dB. The E3 already tracks the preference target closely — ASR's review
says "not much to do" — so struggling to hear a difference against flat is a
reasonable outcome, not a sign anything is broken. The widest, most audible
moves are the cuts near 400 Hz and 2.6 kHz.

**Don't EQ above ~8 kHz.** Headphone measurements above that are dominated by
ear-coupling artifacts specific to the measurement rig, and differ from what
happens on your head. The oratory/Harman preset is capped at 8 kHz for this
reason. The Kuulokenurkka preset is *not* — its `HSC 10000 Hz −2.6 dB` filter is
correcting the fixture as much as the headphone. Delete that line if you want a
like-for-like comparison.
